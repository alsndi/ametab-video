# motion-edit — من Ametab Alsndi

ياخذ فيديو كلام (فيه تسجيل شاشة أو لا) ويطلّع ريل 9:16 فيه:
- كابشن `talk-reel`: خط Tajawal Black، أبيض بحافة سوداء، والكلمة تصفر لما تنقال.
- زوم (Punch-in) على الوجه في اللحظات المهمة.
- انتقال زوم مع فلاش عند تغيّر اللقطة.
- إشارات صفراء مرقّمة، تنبض وفيها موجة لمس، على الأماكن اللي المتكلم يشرح عنها.
- مؤثرات صوتية من حزمة المستخدم.
- كليبات موشن Remotion تغطي جزء من الفيديو وصوت المتكلم مستمر.

كل شي يتحدد في ملف خطة واحد `edit.json`، وبعدها `scripts/edit.py` يرندر الفيديو بتمريرة ffmpeg وحدة. المسار `<skill>` تحت يعني مجلد هذا السكل.

## قبل ما تبدأ
- المتطلبات نفس `talk-reel`: ffmpeg وPython وfaster-whisper. ولو بتسوي موشن، تحتاج Node.js 18 أو أحدث.
- اشتغل في مجلد جديد جنب الفيديو، مثلاً `<اسم الفيديو>_edit/`.
- **الأصوات من مكتبة المستخدم (الأفضل):**
  1. شيك: `python "<skill>/scripts/sfx_index.py" stats`.
  2. لو ما في فهرس، اسأل المستخدم وين مجلد أصواته، وابنه مرة وحدة: `python "<skill>/scripts/sfx_index.py" build "<folder>"`. ياخذ تقريباً دقيقة لكل 4000 صوت، وينحفظ في `~/.ametab-video/sfx_index.json` على جهازه بس.
  3. بعدها في الخطة اكتب `"role": "whoosh"` بدال `"file"`. الأنواع المتوفرة: whoosh وpop وclick وimpact وriser وding وnegative وglitch وtyping وcamera وnotify.
  4. السكربت يختار الصوت المناسب، ويضبط مستواه لحاله.
  5. لو المستخدم يبي يسمع الخيارات: `sfx_index.py audition whoosh out.mp3`. ولو ما عجبه صوت معيّن: `sfx_index.py ban <part of name>`.
- **أو حزمة جاهزة:** فكّها في `<work>/sfx/`، واستخدم `"file"`.
- **لا تنسخ الأصوات للإضافة ولا ترفعها**، لأن أغلب الحزم والمكتبات تمنع إعادة النشر.
- لو ما عنده أصوات، اسأله. لا تنزّل أصوات من النت بدون إذنه.

## الخطوات

### 1. افهم الفيديو
```
python "<skill>/scripts/frames.py" cuts  "<video>"
python "<skill>/scripts/frames.py" sheet "<video>" "<work>/frames/sheet.jpg" 0.5
```
- `cuts` يعطيك أوقات القصّات، مثل الانتقال من الكاميرا لتسجيل الشاشة.
- `sheet` يطلّع صورة فيها فريم كل نص ثانية. افتحها وشوف وين الكلام للكاميرا ووين الشاشة.

### 2. فرّغ الكلام
```
python "<skill>/../talk-reel/scripts/transcribe.py" "<video>" "<work>/words.json" --model medium --lang ar
```
اقرأ الكلمات مع أرقامها (index) وأوقاتها، وحدد الأخطاء الإملائية. التصحيحات تنحط في `word_fixes` داخل الخطة، ولا تعدّل `words.json` نفسه.

### 3. حدد أماكن الإشارات بدقة
لكل خطوة يشرحها المتكلم ("تروح على الإعدادات"، "اضغط هنا"):
```
python "<skill>/scripts/frames.py" strip "<video>" <ثانية_البداية> "<work>/frames/s1.jpg"
```
- تطلع لك 8 فريمات، بين كل وحدة والثانية 0.2 ثانية، وعليها شبكة. كل فريم مقاسه 270×480، فاضرب الإحداثيات في 4 عشان تطلع إحداثيات 1080×1920.
- **اختر نافذة الإشارة لما العنصر يكون ثابت.** تسجيلات الشاشة فيها سكرول وزوم، والإشارة لازم تبدأ بعد ما توقف الحركة وتنتهي قبل الحركة الجاية. لا تخمّن المكان من فريم واحد.
- العنصر الصغير، مثل أيقونة أو زر تفعيل، استخدم له `ring`. والصف الكامل، مثل خيار في الإعدادات، استخدم له `box`.
- `tap` هو وقت الضغطة ومكانها. حطه قبل ما تتغير الشاشة بشوي.

### 4. موشن Remotion (اختياري)
لو المستخدم طلب موشن بعد جملة معيّنة:
1. انسخ `<skill>/remotion/` إلى `<work>/motion/`، وشغّل فيه `npm install`. أول مرة ياخذ دقيقة.
2. القوالب الموجودة:
   - `TitleCard`: عنوان أبيض وكلمة صفراء، وسطر تحته، وإيموجي كبير.
   - `BatteryBoost`: بطارية تنشحن من 15% إلى 100%.
   
   تقدر تسوي قالب جديد في `src/`، وتسجّله في `Root.tsx`.
3. مدة الكليب لازم تساوي الفراغ اللي بيغطيه بالضبط:
   ```
   npx remotion render src/index.ts TitleCard ../title.mp4 --props="{\"seconds\":3.2,\"title\":\"...\",\"highlight\":\"...\"}"
   ```
4. قبل الرندر الكامل، طلّع صورة من نص الكليب بـ `npx remotion still ... --frame=40` وشوفها. لا تحط شي مهم بين y=1250 وy=1400، لأن الكابشن ينزل هناك.
5. الكليب يبدأ بعد ما تخلص الجملة اللي طلبها المستخدم، يعني من `e` آخر كلمة فيها، وينتهي عند القصّة الجاية. صوت المتكلم يكمل فوقه.

### 5. اكتب الخطة `<work>/edit.json`
```json
{
  "source": "../video.mp4",
  "words": "words.json",
  "out": "reel.mp4",
  "word_fixes": {"15": "مفعّليها"},
  "line_breaks": [11, 14, 21],
  "screen_ranges": [[9.68, 26.99]],
  "screen_margin_v": 200,
  "segments": [
    {"start": 0.00, "end": 2.14, "zoom": 1.18},
    {"start": 6.10, "end": 9.68, "type": "clip", "file": "battery.mp4"},
    {"start": 9.68, "end": 10.00, "type": "trans", "zoom": 1.35},
    {"start": 32.46, "end": 33.84, "zoom": 1.22}
  ],
  "markers": [
    {"n": 1, "start": 10.40, "end": 11.50, "ring": [268, 1288, 85], "tap": [11.30, 268, 1288]},
    {"n": 2, "start": 14.00, "end": 15.02, "box": [675, 1226, 540, 120], "tap": [14.85, 820, 1226]}
  ],
  "marker_color": "#FFD60A",
  "hearts": [{"start": 35.12, "end": 36.70, "x": 540, "y": 1150}],
  "sfx_dir": "sfx",
  "sfx": [
    {"file": "06_Impact_Hit.wav", "at": 0.0, "vol": 0.45},
    {"file": "01_Whoosh.wav", "at": 9.2, "vol": 0.55}
  ],
  "marker_sfx": {"appear": "09_Pop.wav", "tap": "08_UI_Click.wav"},
  "loudness": -15
}
```

| المفتاح | وش يسوي |
|---|---|
| `word_fixes` | تصحيح كلمات حسب رقمها |
| `line_breaks` | أرقام الكلمات اللي يبدأ منها سطر كابشن جديد. استخدمه عشان كل خطوة من الشرح تبدأ بسطر جديد، وعشان ما تنفصل كلمتين مرتبطات مثل «ما مفعّليها» |
| `screen_ranges` | أوقات تسجيل الشاشة. الكابشن فيها ينزل لتحت (`screen_margin_v`) عشان ما يغطي الإشارات |
| `segments` | أي وقت ما له segment يطلع عادي بدون زوم. والأنواع: `cut` (الافتراضي) زوم ثابت، ومعه `anchor_y` (0.3 يخلي الوجه فوق). `trans` زوم من `zoom` إلى 1 مع فلاش، وخله 0.3 ثانية عند القصّة. `clip` يحط ملف موشن بدل الصورة |
| `markers` | `ring: [x, y, r]` دائرة، أو `box: [cx, cy, w, h]`. `n` رقم الخطوة. `tap: [t, x, y]` موجة اللمس |
| `marker_sfx` | صوت يطلع تلقائياً مع ظهور كل إشارة، وصوت ثاني مع كل ضغطة. تقدر تحط اسم ملف، أو `"role:pop"` و`"role:click"` من الفهرس |
| `sfx` | `file` (داخل `sfx_dir`) أو `role` (من الفهرس)، و`at` الثانية، و`vol` مستوى الصوت من 0.2 إلى 0.8. وتلقى الأصوات اللي انختارت فعلاً في `<out>.sfx.json` |
| `sfx_seed` | غيّره، مثلاً لـ `"2"`، عشان يختار أصوات ثانية من نفس الأنواع |

**وين تحط الأصوات والتأثيرات (ابدأ من هنا وعدّل حسب الفيديو):**
- **الهوك (أول ثانيتين):** زوم 1.15 إلى 1.2، ومعه صوت Impact أو Boom خفيف.
- **تغيير الزوم بين الجمل:** Swoosh قصير قبل القصّة بـ 0.05 ثانية.
- **الدخول للشاشة والطلوع منها:** segment من نوع `trans`، ومعه Whoosh يبدأ قبله بـ 0.4 ثانية.
- **الكلمة القوية** (مثل «تستنزف» أو «خطير»): زوم 1.2، ومعه Glitch أو Hit.
- **«لايك» أو «تابعني»:** قلب، ومعه Pop.
- **الموشن:** Whoosh عند الدخول، وRiser تحت الحركة، وDing عند الذروة.
- **لا تكثّر.** أصوات أقل أحسن من صوت كل ثانية، وصوت المتكلم لازم يبقى أعلى شي.

### 6. الرندر
```
python "<skill>/scripts/edit.py" "<work>/edit.json"
```

### 7. افحص قبل ما تسلّم
- طلّع فريم من كل إشارة، وفريم من كل انتقال، وفريم من كل موشن:
  `ffmpeg -v error -ss <t> -i reel.mp4 -frames:v 1 -vf scale=270:480 qa/x.jpg`
  
  اجمعها في صورة وحدة بـ `tile` وشوفها. تأكد إن كل إشارة راكبة على عنصرها، وإن الكابشن ما يغطيها، وإن الكلمات العربية بترتيبها الصحيح.
- قيس الصوت بـ `ffmpeg -i reel.mp4 -af ebur128 -f null -`. المطلوب تقريباً ‎-14 إلى ‎-15 LUFS.
- لو وحدة من الإشارات طالعة عن مكانها، رجّع للخطوة 3 وعدّل نافذتها. لا تكبّر المربع عشان يغطي الغلط.

- لو الأصوات من حزمة لها رخصة، اذكر الرخصة.
