# behind-me — خلفية جديدة ورا المتكلم

**الفكرة:** في أوقات تحددها، الخلفية الأصلية تختفي وتطلع مكانها صورة أو فيديو، والمتكلم يبقى قدامها. وباقي الفيديو يمشي عادي.

**المحرك:** القص يصير بـ `depth-text/scripts/matte.py` (موديل Robust Video Matting على الجهاز). الموديل نفسه يحتاجه `depth-text`، فإذا ما كان موجود، **اسأل المستخدم قبل التنزيل**. التفاصيل في `depth-text/SKILL.md`.

## الخطة `<work>/behind.json`
```json
{
  "source": "../video.mp4",
  "segments": [
    {"start": 2.0, "end": 6.5, "bg": "profile.png"},
    {"start": 9.0, "end": 14.0, "bg": "screen.mp4", "bg_start": 3.0},
    {"start": 20.0, "end": 24.0, "bg": "banner.png", "fit": "contain", "align": "top", "pan": true}
  ],
  "dim": 0.15, "blur": 0, "glow": true,
  "out": "behind.mp4"
}
```
| المفتاح | وش يسوي |
|---|---|
| `bg` | صورة (png، jpg، webp) أو فيديو (mp4، mov). الفيديو يلف لحاله لو كان أقصر من المقطع |
| `fit` | `cover` (الافتراضي): يعبي الشاشة ويقص الأطراف، ويناسب السكرين شوت الطولي. `contain`: الصورة كاملة فوق نسخة مغبّشة منها، ويناسب الصور العرضية |
| `align` | لـ `contain` بس. `top` (الافتراضي) يحط الصورة فوق، عشان تبين فوق الراس. وفيه `center` و`bottom` |
| `pan` | زوم بطيء على الصور |
| `dim` | يغمّق الخلفية شوي عشان المتكلم يبرز. 0.15 مناسب |
| `blur` | تغبيش الخلفية. خله 0 لو الخلفية فيها كلام لازم ينقرا |
| `glow` | حافة ضوء ناعمة حول الشخص، عشان القص يبين طبيعي |

## الخطوات
1. **حدد اللحظات:**
   - فرّغ الكلام، وحدد وين يتكلم عن شي يتصوّر، مثل «صفحتي» أو «الموقع هذا» أو «النتيجة».
   - كل مقطع من 3 إلى 8 ثواني.
2. **جهّز الخلفيات:**
   - سكرين شوت طولي يعطي أحسن نتيجة.
   - لا تحط معلومات خاصة في الخلفية بدون ما تسأل المستخدم: إيميلات، أرقام، رسائل.
3. **شيك على الشكل:**
   ```
   python "<skill>/scripts/behind.py" "<work>/behind.json" --still 3.0
   ```
   - أول مرة يقص الفيديو كامل (`*_mask.mp4`)، وياخذ تقريباً 5 ثواني لكل ثانية فيديو على المعالج.
   - المرات الجاية يستخدم نفس القص.
   - **لو غيّرت الفيديو المصدر، احذف ملف القص القديم.**
4. **الرندر:**
   ```
   python "<skill>/scripts/behind.py" "<work>/behind.json"
   ```
5. **افحص:**
   - طلّع فريم قبل كل مقطع، وفريم في نصه، وفريم بعده.
   - تأكد إن القص نظيف حول الشعر واليدين.
   - تأكد إن الكلام المهم في الخلفية مو ورا الراس.
   - الحركة السريعة أو الأشياء اللي يمسكها المتكلم قريب من الكاميرا ممكن تطلع حوافها مو مرتبة. اختار لحظات أهدى.

**ينفع مع:** `talk-reel` و`soft-captions` (للكابشن)، و`depth-text` (لكتابة ورا الظهر فوق الخلفية الجديدة).
