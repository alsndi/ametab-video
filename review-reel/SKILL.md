# review-reel — من Ametab Alsndi

**المدخلات:** تسجيل صوت المستخدم، ومجلد لقطات للمنتج أو المكان.

**الناتج:** ريل 9:16 فيه:
- لقطة جديدة مع كل جملة أو فكرة. أنت تحدد اللقطة، أو السكربت يختار أحلى لحظة.
- كابشن `talk-reel`: Tajawal Black، أبيض، والكلمة تصفر لما تنقال.
- ملصقات صفراء فوق للسعر والمواصفات والتقييم، مثل «السعر 129 ريال» أو «بطارية 20 ساعة».
- موسيقى خلفية تنخفض لحالها لما يتكلم (sidechain ducking)، وترجع ترتفع في الوقفات.
- مؤثرات صوتية اختيارية من حزمة المستخدم.
- الصوت مضبوط على ‎-15 LUFS تقريباً.

## المتطلبات
ffmpeg، وPython مع `numpy` و`opencv-python` و`faster-whisper`، وخط Tajawal.

## الخطوات

### 1. الصوت
- لو المستخدم سجّل صوته، استخدمه مباشرة.
- لو ما سجّل، اكتب له سكربت قصير، 20 إلى 40 ثانية، بأسلوب: «هوك، ثلاث مزايا، عيب واحد بصراحة، السعر، والحكم». وخله يسجّله. **لا تولّد صوت بالذكاء الاصطناعي إلا لو طلب.**
- فرّغ الصوت:
  ```
  python "<skill>/../talk-reel/scripts/transcribe.py" "<vo>" "<work>/words.json" --model medium --lang ar
  ```

### 2. اللقطات
```
python "<skill>/../beat-montage/scripts/scan_clips.py" "<work>/clips" "<work>/clips.json"
```
افتح `clips_sheet.jpg` واعرف وش في كل لقطة: فتح العلبة، تفاصيل، استخدام، مقارنة، وهكذا.

### 3. وزّع اللقطات على الكلام
```
python "<skill>/scripts/review.py" phrases "<work>/words.json"
```
- يطلع لك الكلام مقسّم جمل، ولكل جملة رقمها ووقت بدايتها.
- **طابق كل جملة بلقطة تشرحها.** يعني لما يقول «الصوت قوي» تحط لقطة السماعة، ولما يقول «السعر» تحط لقطة العلبة أو السعر.
- الجملة الطويلة (أكثر من 4 ثواني) قسّمها على لقطتين.
- أول لقطة، الهوك، لازم تكون أقوى لقطة في المجموعة.

### 4. الخطة `<work>/review.json`
```json
{
  "voice": "vo.m4a", "words": "words.json", "scan": "clips.json",
  "shots": [
    {"start": 0.0, "file": "hero.mov", "in": 1.2},
    {"start": 2.6, "file": "detail.mov"},
    {"start": 5.1}
  ],
  "word_fixes": {"3": "آيفون"}, "line_breaks": [7, 15],
  "labels": [{"start": 6.0, "end": 8.5, "text": "السعر 129 ريال"}],
  "music": "bed.mp3", "music_start": 0, "music_vol": 0.22,
  "sfx_dir": "sfx", "sfx": [{"file": "09_Pop.wav", "at": 6.0, "vol": 0.5}],
  "push": 1.06, "out": "review.mp4"
}
```
- `start` يحدد متى تبدأ اللقطة على وقت الصوت.
- `in` من أي ثانية في المقطع تبدأ. لو ما حطيته، يختار السكربت أحلى لحظة من نفس الملف. ولو ما حطيت `file` كمان، يختار أحلى لحظة ما انستخدمت من أي مقطع.
- `labels`: نص قصير بس. **بدون إيموجي**، لأنها تطلع أبيض وأسود. حط مع كل ملصق صوت Pop في `sfx`.
- `music` اختياري. الأغنية من عند المستخدم، ولا تنزّل أغاني من النت.

### 5. الرندر
```
python "<skill>/scripts/review.py" render "<work>/review.json"
```
يكتب كذلك `review.mp4.shots.json`، وفيه وش انختار لكل لقطة.

### 6. افحص
- طلّع فريم من نص كل لقطة، وتأكد إن اللقطة تطابق الكلام اللي يقوله وقتها.
- تأكد إن الملصق ما يغطي المنتج، وإن الكابشن مقروء.
- تأكد إن الموسيقى ما تغطي على الصوت، وقس الصوت بـ `ebur128`.

### 7. التسليم
مسار الفيديو، وجدول صغير (اللقطة، وقتها، والجملة اللي معها)، واقتراح تحسين واحد بس.
