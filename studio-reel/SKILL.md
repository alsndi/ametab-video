# studio-reel — ستايل Ametab الاستوديو

هذا الستايل اللي في فيديوهات المستخدم السابقة، مجلد `مونتاج` على سطح المكتب: التلفون المخترق، وClaude، وبرشلونة، وتحديث كروم. كله يترسم بـ Remotion، والقالب في `motion-edit/remotion/src/Studio.tsx`.

## الشكل
- **الخلفية:** غامقة (`#0b0b10`)، فيها شبكة خفيفة تتحرك، وتوهّج بلون الموضوع.
- **لون الموضوع (`accent`):** لون واحد لكل فيديو. أحمر للتقنية والفلوس، وأخضر للأمان والحماية، وسماوي لبرشلونة والرياضة وكروم، وبرتقالي للعروض والكوبونات. أو اختار أي لون hex.
- **التخطيطات (`layout`):**
  - `full`: وجهك يعبي الشاشة، ومعه زوم اختياري.
  - `split`: الكرت فوق (ارتفاعه 1000 بكسل)، ووجهك تحت، والكابشن على الخط اللي بينهم.
  - `pip`: الكرت يعبي الشاشة، ووجهك في مربع صغير تحت بالنص.
- **الكابشن:** مربع غامق بحواف دائرية، فيه من 3 إلى 5 كلمات. الكلمة اللي تنقال الحين تتلوّن بلون الموضوع، والكلمات المحددة في `keywords` تطلع على خلفية بلون الموضوع.
- **إضافات:** إطار REC بأول ثانيتين (`rec`)، وشريط تقدم رفيع تحت (`progress`).

## الكروت
| `type` | الحقول | متى تستخدمه |
|---|---|---|
| `list` | `n`، `total`، `title`، `emoji` أو `image` | «7 علامات»، «3 أخطاء». كرت لكل رقم، وفوقه عداد وشريط |
| `checklist` | `title`، `items`، `at_words` (اختياري) | «شتسوي؟»، الخطوات. كل بند يتعلّم صح وقت ما ينقال |
| `score` | `label`، `home{name,score,logo}`، `away{...}` | نتيجة مباراة |
| `person` | `image`، `label`، `name` | لاعب أو مدرب أو شخصية، ومعه وصف قصير مثل «اختلف الوضع» |
| `table` | `title`، `rows`، `highlight` | جدول مصروفات، أو مقارنة، أو ترتيب |
| `image` | `image`، `caption` | سكرين شوت أو صورة منتج |
| `text` | `title`، `highlight`، `sub`، `emoji` | فكرة وحدة قوية |

## المتطلبات
ffmpeg، وPython مع `faster-whisper`، وNode.js 18 أو أحدث، وخط Tajawal. ولو تبي أصوات تلقائية، تحتاج فهرس الأصوات (`motion-edit/scripts/sfx_index.py build <folder>`).

## الخطوات

### 1. افهم الفيديو والكلام
```
python "<skill>/../motion-edit/scripts/frames.py" sheet "<video>" "<work>/frames/sheet.jpg" 0.5
python "<skill>/../talk-reel/scripts/transcribe.py" "<video>" "<work>/words.json" --model medium --lang ar
```
- اقرأ الكلمات مع أرقامها، وحدد الأخطاء الإملائية في `word_fixes`.
- لو الفيديو فيه سكتات طويلة، قصّها أول بـ `talk-reel` واشتغل على الناتج.

### 2. صمّم الإيقاع (beats)
- **أول 2-3 ثواني:** `full` مع `zoom` من 1.08 إلى 1.12، و`rec`، وهوك.
- **أول ما يبدأ الشرح:** حوّل لـ `split` أو `pip` مع كرت. **كل فكرة جديدة لها كرت جديد**، وكل كرت من 2 إلى 6 ثواني.
- **قائمة مرقّمة:** كرت `list` لكل رقم، وكلها بنفس `total`.
- **الخطوات أو الحلول:** كرت `checklist`، و`at_words` يحدد الكلمة اللي يتعلّم عندها كل بند.
- **تسجيل الشاشة:** خله `full` بدون كرت. ما يحتاج تقسيم.
- **الختام والطلب (لايك ومتابعة):** `full`.
- خل `face_y` على مكان الوجه في المصدر، تقريباً 0.25 إلى 0.35، عشان القص تحت في split وpip يمسك الوجه.
- `keywords`: من 3 إلى 6 كلمات بس، هي أهم كلمات الفيديو.

### 3. الخطة `<work>/studio.json`
```json
{
  "source": "../video.mp4", "words": "words.json",
  "word_fixes": {"15": "مفعّليها"}, "line_breaks": [11, 18],
  "accent": "green", "face_y": 0.28,
  "keywords": ["مخترق", "الكاميرا"], "rec": 2.0, "progress": true,
  "beats": [
    {"at_word": 0, "layout": "full", "zoom": 1.1},
    {"at_word": 6, "layout": "split", "card": {"type": "list", "n": 1, "total": 7, "title": "التلفون يحمى بلا سبب", "emoji": "🌡️"}},
    {"at_word": 30, "layout": "pip", "card": {"type": "checklist", "title": "شتسوي؟", "items": ["امسح التطبيقات الغريبة", "راجع الصلاحيات"], "at_words": [31, 36]}},
    {"start": 40.0, "layout": "full"}
  ],
  "auto_sfx": true,
  "sfx": [{"role": "impact", "at": 0.0, "vol": 0.45}],
  "out": "studio.mp4"
}
```
- المشهد يبدأ بـ `at_word` أو `start`، ويستمر لين المشهد اللي بعده.
- الصور (`image`، `logo`) تنحط بمسارها، والسكربت ينسخها لحاله.
- `auto_sfx`: صوت whoosh مع كل تغيير تخطيط، وpop مع كل كرت جديد، وding مع كل علامة صح. كلها من مكتبة المستخدم.

### 4. شيك على الشكل قبل الرندر الكامل
```
python "<skill>/scripts/build.py" "<work>/studio.json" --still 5.0
```
طلّع صورة من كل نوع تخطيط وكرت مستخدم. شيك إن الكرت ما يطلع برا الشاشة، وإن الوجه داخل القص، وإن الكابشن ما يغطي على الكرت.

### 5. الرندر
```
python "<skill>/scripts/build.py" "<work>/studio.json"
```
- الرندر ياخذ تقريباً 4 أضعاف مدة الفيديو. يعني فيديو 40 ثانية ياخذ قرابة 3 دقايق.
- يكتب كذلك `studio.beats.json`، وفيه المشاهد والأصوات اللي انختارت.

### 6. الكفر بنفس الستايل
```
python "<skill>/../cover-thumb/scripts/make_covers.py" frame.png covers --title "هل هاتفك" --highlight "مخترق؟" --tag "7 علامات" --look studio --accent green --rec
```

### 7. افحص وسلّم
- طلّع فريم من كل مشهد، وقس الصوت بـ `ebur128`. المطلوب تقريباً ‎-14 LUFS.
- سلّم: المسار، وجدول المشاهد (الوقت، والتخطيط، والكرت)، واللون اللي اخترته ولماذا، واقترح تعديل واحد.
