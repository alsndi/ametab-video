# trial-reels — نسخ تجربة من فيديو واحد

إنستقرام فيه ميزة **Trial Reels**: تنشر الريل لغير المتابعين أول، وبعدها تشوف نتيجته. هذا السكل يجهّز لك النسخ اللي تجربها. كل نسخة تتغيّر في **شي واحد أو شيئين بس**، عشان تعرف وش اللي فرق:

| المتغيّر | المفتاح |
|---|---|
| أول جملة | `start_word`: النسخة تبدأ من كلمة ثانية، وتتجاوز المقدمة البطيئة |
| الهوك المكتوب فوق، لأول ثانيتين ونص | `hook`: `title`، والكلمة الملوّنة `highlight` |
| ستايل الكابشن | `style`: `fill` (أصفر عريض)، أو `soft` (ناعم وAmiri)، أو `word` (الكلمة الحالية ملوّنة) |

## الخطوات
1. **فرّغ الكلام** بـ `talk-reel/scripts/transcribe.py`، واقرأ الكلمات مع أرقامها.
2. **اختار 3 نسخ، وبالأكثر 5:**
   - **هوكات من أنواع مختلفة:** سؤال («ليش بطاريتك تخلص بسرعة؟»)، ونتيجة («بطارية تطوّل يوم كامل»)، وفضول («إعداد مخفي»)، وخطأ شائع («لا تسوي هذا بجوالك»).
   - **أول جملة:** جرّب نسخة تبدأ من أقوى جملة في الفيديو، مو من البداية.
   - **لا تغيّر كل شي بكل نسخة.** وخل وحدة من النسخ هي «النسخة الأصلية» عشان تقارن عليها.
   - **لا تخترع وعود أو أرقام ما قالها المتكلم.**
3. **الخطة `<work>/trial.json`:**
   ```json
   {
     "source": "../video.mp4", "words": "words.json", "word_fixes": {"15": "مفعّليها"},
     "cut": true, "hook_seconds": 2.6,
     "variants": [
       {"name": "A-question", "start_word": 0, "style": "fill",
        "hook": {"title": "ليش بطاريتك", "highlight": "تخلص بسرعة؟"},
        "tests": "هوك سؤال + البداية الأصلية", "caption": "..."},
       {"name": "B-result", "start_word": 3, "style": "soft",
        "hook": {"title": "بطارية تطوّل", "highlight": "يوم كامل"},
        "tests": "هوك نتيجة + يبدأ من «رح تخلي» + ستايل ناعم", "caption": "..."}
     ],
     "out_dir": "trials"
   }
   ```
   - `caption`: أول سطر في كابشن النشر لهالنسخة. استخدم سكل `instagram-agent:ig-caption` إذا كان متاح.
4. **الرندر:**
   ```
   python "<skill>/scripts/trial.py" "<work>/trial.json"
   ```
   يطلّع لكل نسخة ملف `trials/<name>.mp4`، ومعهم ملف `trials/TRIALS.md`. الملف فيه جدول النسخ، والكابشن لكل وحدة، وطريقة المقارنة.
5. **افحص:**
   - طلّع فريم من الثانية الأولى لكل نسخة. هذي أهم لحظة: الهوك مقروء، وما يغطي الوجه.
   - تأكد إن كل نسخة تبدأ من بداية جملة، مو من نص كلمة.
6. **سلّم:** المسارات، وجدول النسخ، ونصيحة للمقارنة. بعد 24 إلى 48 ساعة، قارن نسبة اللي كمّلوا الفيديو، والحفظ، والإرسال، مو اللايكات بس. والنسخة اللي تفوز، انشرها لمتابعينك.
