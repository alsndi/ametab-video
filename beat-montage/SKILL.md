# beat-montage — من Ametab Alsndi

ياخذ مجلد مقاطع وأغنية، ويطلّع فيديو 9:16 فيه:
- القص على نبضات الأغنية: كل نبضتين بالبداية، وبعد الذروة (drop) يصير كل نبضة.
- من كل مقطع تنقص أحلى لحظة: صورة واضحة، فيها حركة بس مو مهزوزة، وإضاءة كويسة. وما تتكرر نفس اللحظة مرتين.
- ضربة زوم مع فلاش خفيف على النبضات القوية (downbeats)، وزوم بطيء على كل لقطة.
- عنوان اختياري بأول ثانيتين: أبيض وكلمة صفراء.
- الأغنية مضبوطة على ‎-14 LUFS، وفيها fade في الآخر.

## المتطلبات
ffmpeg وPython مع `numpy` و`opencv-python`. ما يحتاج librosa.

## الخطوات

### 1. جهّز المواد
- حط المقاطع في مجلد واحد، مثلاً `<work>/clips/`. الصيغ المدعومة: mp4 وmov وm4v وmkv وwebm.
- الأغنية: ملف المستخدم نفسه. **لا تنزّل أغاني من النت.** ونبّهه إن الأغاني المحمية ممكن تنكتم على إنستقرام، وإن الأفضل يضيف الأغنية من مكتبة إنستقرام لو بينشر هناك.
- اسأله وش طول الفيديو اللي يبيه، و**من وين في الأغنية** يبدأ. الأفضل قبل الذروة بشوي.

### 2. حلّل الأغنية
```
python "<skill>/scripts/beats.py" "<song>" "<work>/beats.json" --start 32 --length 20
```
- `--start` لازم يساوي `music_start` في الخطة. وخل `--length` أطول من مدة الفيديو بشوي.
- يطبع لك الـ BPM ووقت الذروة. لو الـ BPM يطلع نص أو ضعف السرعة اللي تحسها، صح الوضع بـ `beats_per_shot` في الخطة.

### 3. حلّل المقاطع
```
python "<skill>/scripts/scan_clips.py" "<work>/clips" "<work>/clips.json"
```
- افتح `clips_sheet.jpg`، وفيها صف لكل مقطع، واعرف وش في كل واحد.
- المقاطع اللي فيها شخص يتكلم، أو نص على الشاشة، أو مقاطع مكررة، حطها في `exclude`.
- لو فيه لقطة لازم تكون أول وحدة (الهوك)، حطها في `shots` مع `in`. وأول لقطة لازم تكون أقوى لقطة.

### 4. اكتب الخطة `<work>/plan.json`
```json
{
  "music": "song.mp3", "music_start": 32, "duration": 15,
  "beats": "beats.json", "scan": "clips.json",
  "beats_per_shot": 2, "fast_after_drop": 1,
  "shots": [{"file": "hero.mov", "in": 2.4}],
  "exclude": ["talking.mp4"],
  "punch": true, "push": 1.06,
  "text": [{"start": 0, "end": 1.9, "title": "يوم", "highlight": "تصوير"}],
  "fade_out": 1.0, "out": "montage.mp4"
}
```
| المفتاح | وش يسوي |
|---|---|
| `beats_per_shot` | طول اللقطة بالنبضات: 1 سريع، 2 عادي، 4 هادي |
| `fast_after_drop` | طول اللقطة بالنبضات بعد الذروة. حط 0 لو ما تبي يسرّع |
| `shots` | لقطات بترتيب ثابت من البداية، والباقي يتعبّى لحاله |
| `punch` | ضربة زوم مع فلاش على النبضات القوية |
| `push` | زوم بطيء طول اللقطة. 1 يعني بدون زوم |
| `text` | عنوان بخط Tajawal، والمكان الافتراضي `y`: 820 |

### 5. الرندر
```
python "<skill>/scripts/montage.py" "<work>/plan.json"
```
يكتب كذلك `montage.shots.json`، وفيه كل لقطة: من أي مقطع، ومن أي ثانية، وكم طولها. ارجع له لو المستخدم قال «غيّر اللقطة الثالثة».

### 6. افحص
- طلّع فريم من نص كل لقطة واحد ورا الثاني، وشوف إن ما فيه لقطة سودا أو مكررة أو مهزوزة.
- تأكد إن العنوان مقروء وما يغطي الشي المهم في الصورة.
- لو المقاطع ما تكفي، السكربت بيوقف ويقولك. قصّر `duration`، أو زِد `beats_per_shot`، أو اطلب مقاطع زيادة.

### 7. التسليم
مسار الفيديو، والـ BPM، وكم لقطة طلعت، وأي لقطة بدأ فيها. واقترح تعديل واحد بس، مثل «أبدأ بلقطة القهوة بدال الباب؟».
