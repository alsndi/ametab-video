# talk-reel — من Ametab Alsndi

تاخذ فيديو شخص يتكلم، وتطلّع ريل عمودي 1080×1920 فيه:
- السكتات الطويلة مقصوصة، والتأتأة (اه، امم) محذوفة لو طلبها المستخدم.
- كابشن عربي، كل مرة تظهر 2 إلى 3 كلمات، والكلمة اللي تنقال الحين تكبر وتتلوّن. كل جملة تاخذ لون جديد من ألوان البراند.
- صوت مضبوط على ‎-14 LUFS، وهو المستوى المناسب لإنستقرام وتيك توك.

كل الشغل يصير على جهاز المستخدم. السكربتات موجودة في `scripts/` داخل مجلد هذا السكل، والستايل في `brand.json`.

## قبل ما تبدأ
1. تأكد إن `ffmpeg` و `ffprobe` موجودين (`ffmpeg -version`). لو مو موجودين، علّم المستخدم يثبتهم (ويندوز: `winget install Gyan.FFmpeg`، ماك: `brew install ffmpeg`).
2. تأكد من Whisper: `python -c "import faster_whisper"`. لو ما اشتغل، اطلب إذن المستخدم وبعدها ثبّت `pip install faster-whisper`. لو فشل التثبيت جرّب `pip install openai-whisper`.
3. اشتغل في مجلد جديد جنب الفيديو، مثلاً `<اسم الفيديو>_reel/`، عشان ما تتلخبط ملفات المستخدم.

## الخطوات

### 1. التفريغ
```
python "<skill>/scripts/transcribe.py" "<video>" "<work>/words.json" --model small --lang ar
```
- `small` سريع وكافي لأغلب الحالات. لو اللهجة ثقيلة أو التفريغ فيه أخطاء كثيرة، جرّب `medium` أو `large-v3`.
- للإنجليزي استخدم `--lang en`.

### 2. راجع الكلام
افتح `words.json` واقرأ النص كامل، وبعدها:
- صحّح الإملاء الواضح في `"w"`، مثل أسماء العلامات التجارية والكلمات اللي Whisper سمعها غلط. **لا تغيّر `s` و `e`**.
- لو فيه جملة معادة أو غلطة وعادها المتكلم، احذف كلمات المحاولة الأولى من الملف عشان تنقص.
- اعرض على المستخدم النص النهائي بسطر أو سطرين، ولو فيه شي تشك فيه اسأله.

### 3. الرندر
```
python "<skill>/scripts/render.py" "<video>" "<work>/words.json" "<work>/reel.mp4" --drop-fillers
```
الخيارات:
- `--gap 0.35`: أي سكتة أطول من كذا تنقص. خلها 0.25 لو تبي إيقاع أسرع، و0.5 لو تبيه طبيعي أكثر.
- `--pad 0.08`: نفَس صغير يبقى قبل وبعد كل كلمة، عشان القص ما يطلع حاد.
- `--no-cut`: يحط الكابشن بس، بدون أي قص.
- `--brand path.json`: ستايل ثاني بدل الافتراضي.

السكربت يطلّع جنب الفيديو `reel.mp4.ass` (ملف الكابشن) و `reel.mp4.plan.json`، وفيه كم ثانية انقصت.

### 4. افحص قبل ما تسلّم
- طلّع 3 صور من أماكن مختلفة في الفيديو وشوفها بنفسك:
  `ffmpeg -v error -ss 3 -i reel.mp4 -frames:v 1 check1.jpg`
- تأكد إن الكابشن مقروء، والحروف العربية متصلة ومو مقطعة، والنص ما يطلع برا الشاشة، وما يغطي الوجه.
- لو الحروف طالعة مربعات أو منفصلة، غيّر `font` في `brand.json` لخط يدعم العربي (Arial أو Segoe UI أو Cairo لو مثبت).
- لو الكابشن ماسك على الوجه، زِد `margin_v` أو نقّصه.

### 5. التسليم
قل للمستخدم: مسار الفيديو، والمدة قبل وبعد، وكم مقطع انقص. وعطه خيارين للتعديل: إيقاع أسرع أو أبطأ، وألوان أو خط ثاني.

## الستايل (brand.json)
| المفتاح | وش يسوي |
|---|---|
| `font`, `font_size`, `bold` | الخط وحجمه |
| `text_color`, `outline_color`, `outline`, `shadow` | لون الكلام العادي وإطاره وظله |
| `highlight_mode` | `fill` (الافتراضي): الكلام أبيض، وكل كلمة تنقال تصير صفراء وتبقى صفراء لين تخلص الجملة. `word`: بس الكلمة الحالية تتلوّن |
| `fill_color` | لون التعبئة في وضع `fill` (أصفر ‎#FFD60A‎) |
| `palette` | في وضع `word`: ألوان الكلمة الحالية، كل جملة تاخذ اللي بعده |
| `highlight_scale` | كم تكبر الكلمة الحالية (100 = ما تكبر، 115 = ‎15%‎) |

الستايل الافتراضي حق Ametab: خط **Tajawal Black**، كلام أبيض بحافة سوداء، والتعبئة صفراء. لو Tajawal مو مثبت على الجهاز، بيطلع خط ثاني بداله. ثبّته من Google Fonts، أو غيّر `font`.
| `max_words`, `max_chunk_seconds` | كم كلمة تظهر بنفس الوقت |
| `margin_v` | بعد الكابشن من تحت (560 يخليه فوق أزرار إنستقرام) |

لو المستخدم طلب ألوان معيّنة، عدّل `palette` في نسخة جديدة من `brand.json` داخل مجلد الشغل، ومرّرها بـ `--brand`. لا تعدّل الملف الأصلي إلا لو المستخدم قال إنه يبي يغيّر الستايل الافتراضي.
